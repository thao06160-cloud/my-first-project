# Thảo — Daily vlog dễ thương (bản nháp)

**[▶ Xem video MP4](./Thao-Daily-Cute-ban-nhap.mp4)** · **[Tải dự án chỉnh sửa](./Thao-Daily-Cute-du-an.zip)**

Video dọc 720×1280, 30fps, khoảng 66 giây. Có voice gốc, hook lưới 2×2 cân đều, chữ nhấn lớn, sticker chuyển động, zoom nhẹ, chuyển cảnh và âm thanh pop/chime/swoosh.

**Trạng thái:** Đây là bản nháp để xem bố cục. Chưa có phụ đề karaoke căn theo từng từ; nhịp chữ keyword cũng cần đối chiếu với voice. Chưa phải bản hoàn thiện.

Thứ tự clip: văn phòng → họp → chùa buổi tối → selfie → sân chùa → chánh điện → selfie → làm việc. Hook có bảng giá minh họa tự tạo và ba footage; ô trên phải hiện dùng footage làm việc.

![Hook bốn ô](./hook.png)

## Chỉnh sửa

Giải nén `Thao-Daily-Cute-du-an.zip`. Cần Node.js 20.19+, 22.13+ hoặc 24+.

```sh
cd Thao-Daily-Cute
npm ci
npm run dev -- --no-open
```

Chọn composition **Thao-Daily-Cute**; chỉnh riêng hook tại **Thao-Hook-4-O**. Bản dựng cũ **Thao-MotNgay** vẫn được giữ.

Font Baloo 2 và Be Vietnam Pro kèm giấy phép SIL Open Font License trong `public/daily-vlog/fonts/`.
